# Notes Manager

A simple web app to write and manage your notes.

## What it does

- Write new notes
- Save notes in your browser
- Edit existing notes
- Delete notes you don't need
- Shows all your notes in a nice grid

## How to use

1. Open `index.html` in your web browser
2. Type your note in the text box
3. Click "Add Note" to save it
4. Use "Edit" to change a note
5. Use "Delete" to remove a note

## Files

- `index.html` - The main page
- `script.js` - Makes the app work
- `style.css` - Makes it look good

## Features

- Works offline (saves in your browser)
- Clean and simple design
- Easy to use on phones and computers
- No setup needed - just open and use

Your notes stay saved even when you close the browser!
